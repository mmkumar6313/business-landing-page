# SmileCare Dental Clinic - Landing Page

A responsive one-page business website (demo) built with plain HTML, CSS and a
little JavaScript. No frameworks, no build step.

## Features
- Sticky navigation and smooth scrolling
- Hero section with call-to-action
- Services grid (6 services), stats band, patient testimonials
- Appointment form with client-side validation and callback message
- Fully responsive (mobile menu simplification included)

## How to view
Open `index.html` in any browser, or host it free on GitHub Pages /
Netlify / Vercel.
